# VESPER — COSMIC PORTAL

Новая навигация: стартовый экран — полноэкранная космическая карта. Центральное светило открывает Главную, отдельные объекты — Личный кабинет, Настройки, Цели и задачи, Направления, Развитие. Небольшие планеты на карте — активные цели.

Главная содержит задачи, цели, быстрые действия, направления и доступ к дневнику цикла. Личный кабинет показывает уровень, XP, кристаллы, звёздную пыль и достижения.

## Установка
1. Перед обновлением экспортируйте JSON через Настройки → Экспорт.
2. Загрузите ВСЕ файлы архива в корень GitHub laworu/vesper, сохранив папку api.
3. Замените одноимённые файлы, сделайте commit в main, дождитесь Vercel.
4. После деплоя очистите кэш сайта и проверьте данные.

Данные остаются в прежнем localStorage vesper3. Это не облачный аккаунт: личный кабинет — локальный профиль, без регистрации и синхронизации. Кристаллы пока только отображаются и будут использоваться в будущей косметической системе Кайро.
