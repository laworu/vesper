# VESPER 5.0 — цельная версия интерфейса

В этом архиве **полный сайт**, а не только обновлённые файлы. Это версия для установки в существующий репозиторий `laworu/vesper`.

## Что включено
- Пять основных разделов: Вселенная, Цели и задачи, Направления, Развитие, Настройки.
- Космическая карта, где активные цели представлены кликабельными объектами. Три визуальных темы.
- Цели с этапами, тестами, заметками, сроками и сложностью; самостоятельные задачи и задачи, привязанные к целям.
- Полезные привычки и нейтральный журнал нежелательных привычек.
- Учебные тесты, дневник чтения, настройки направлений.
- Приватный дневник цикла в разделе «Направления», доступен и при скрытом календаре.
- XP, уровни, характеристики, кристаллы и архив завершённых целей.
- Резервное копирование и импорт JSON через настройки.

## Как установить
1. На действующем сайте откройте **Настройки → Экспортировать данные** и сохраните JSON. Также сделайте резервную копию репозитория.
2. Распакуйте ZIP. Загрузите содержимое папки сайта в **корень** GitHub-репозитория, сохранив путь `api/news.js`.
3. Убедитесь, что файлы `index.html`, `app.js`, `style.css`, `vesper4.js`, `vesper4.css`, `vesper5.js`, `vesper5.css`, `icon.svg` и `manifest.webmanifest` находятся в корне.
4. Создайте commit в ветке `main`. Vercel выполнит автоматическое развёртывание.
5. После деплоя обновите страницу с очисткой кэша. Проверьте карту целей, дневник цикла, задачи и экспорт.

## Данные
Приложение сохраняет прежний ключ `localStorage` — `vesper3`. **Данные не сбрасываются** при установке. XP-журнал строится на основании существующих записей, без повторного начисления при каждом открытии.

## Ограничения
Это локальная версия без авторизации и синхронизации между устройствами. Данные хранятся в браузере и не защищены отдельным паролем. Для чувствительных данных используйте только личное устройство. AI-Кайро отложен по договорённости. Уведомления при закрытом сайте и облачная синхронизация не включены. Космос использует Canvas 2D, а не полноценный 3D-движок. Календарный прогноз цикла не является методом контрацепции.

## Проверки
Синтаксис всех JavaScript-файлов проверен Node.js. Проведены автоматические сценарии в Chromium: открытие цели с карты, переходы по пяти разделам, открытие и сохранение записи дневника цикла, создание цели. Финальная проверка после публикации на Vercel остаётся необходимой.
