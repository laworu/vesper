# VESPER — первая публикуемая веб-версия

## Запуск
Откройте `index.html` в браузере. Для полноценной PWA-установки и работы service worker разместите проект на HTTPS (например, Vercel).

## Публикация на GitHub + Vercel
1. Создайте приватный репозиторий `vesper` на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория (не ZIP).
3. В Vercel: Add New → Project → Import Git Repository → `vesper`.
4. Framework Preset: Other; Build Command: пусто; Output Directory: `.`; Deploy.
5. Откройте адрес, выданный Vercel. На iPhone в Safari: Поделиться → На экран Домой.

## Реализовано
- Космическая интерактивная 2D-карта разделов с масштабированием (не Three.js/3D).
- Миссии и архив завершенных звезд, статистика этапов и времени, уведомление о сверхновой (без анимации взрыва).
- Тесты ЕГЭ с процентом правильных ответов, темы для повторения.
- Задачи, приоритеты, занятые интервалы и базовый автоматический подбор свободного окна.
- Привычки, награды и символический котик.
- Ручные записи цикла и самочувствия.
- Ссылки на источники космических новостей.
- Экспорт публичного отчета и JSON-резервная копия.
- Локальное хранение в браузере, PWA-манифест.

## Еще не реализовано
- Настоящая 3D-система, физика орбит и анимация сверхновой.
- Регистрация, общая база данных, синхронизация между устройствами, друзья в реальном времени.
- Apple Health / HealthKit (нужна отдельная iOS-интеграция).
- Автоматическая новостная лента и полноценные интервальные повторения.
- Серверная защита и синхронизация личных медицинских записей.

## Приватность
Данные хранятся в localStorage на конкретном устройстве и могут пропасть при очистке браузера. JSON-резервная копия включает чувствительные записи о цикле и самочувствии — не делитесь ею. Публичный текстовый отчет их не содержит.
