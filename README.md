# VESPER 2.1

Статический сайт с интерактивной космической картой, планировщиком, миссиями, привычками, архивом достижений и локальным онбордингом.

## Новое
- Первое открытие: 3 шага настройки профиля (имя, необязательный возраст, пол, цели, темп, тема).
- При выборе женского пола предлагается раздел «Мой цикл», его можно отключить. При выборе мужского пола или пропуске выбора раздел скрыт.
- Настройки профиля можно изменить позднее.
- Короткий, нейтральный язык интерфейса.
- Данные хранятся локально в браузере. Это не облачная регистрация, у каждого устройства своя копия данных.

## Публикация
Загрузите все файлы из папки vesper в корень репозитория GitHub. Vercel автоматически развернет новую версию.

## Ограничения
Нет облачных аккаунтов, синхронизации между устройствами, HealthKit и настоящей многопользовательской системы. Для этого нужен сервер и база данных.
