# VESPER 3.0 — рабочий прототип

Статический HTML/CSS/JavaScript + необязательная Vercel serverless-функция `/api/news` для новостей NASA.

## Публикация
1. Сохраните резервную копию текущего репозитория и браузерных данных.
2. Загрузите `index.html`, `style.css`, `app.js`, `icon.svg`, `manifest.webmanifest`, `README.md` в корень GitHub-репозитория. Папку `api` вместе с `api/news.js` загрузите как папку.
3. В Vercel: Framework Preset = Other, Root Directory = `./`, Build Command не нужен, Output Directory = `.` (или стандартная настройка для статического сайта).
4. После деплоя откройте сайт. Важно: прежние локальные данные VESPER 2.x не мигрируют автоматически в VESPER 3.0.

## Реализовано
- Первоначальная анкета и профиль, настройка вида вселенной и раздела цикла.
- Canvas-космос с разными темами, пульсаром, созвездием, орбитой, ядром, миссиями и архивом. Уважает `prefers-reduced-motion`.
- Миссии с вложенными этапами, тестами, заметками и временем; архив завершенных миссий.
- Задачи, привычки, звездная пыль и развитие галактики.
- Календарь цикла с дневными записями, симптомами, выделениями и отметками интимной близости. Прогноз календарный и не является методом контрацепции.
- Обсерватория: новости NASA через Vercel API и официальные источники при недоступности ленты.
- Экспорт/импорт JSON.

## Не реализовано
- Настоящая регистрация, синхронизация, социальные функции и обмен календарем цикла: необходимы Supabase Auth, серверные права доступа и отдельное согласие на передачу чувствительных данных.
- Точная 3D-модель космоса: текущая карта детализирована средствами Canvas 2D, а не WebGL.
- Клиническое прогнозирование овуляции: календарная оценка приблизительная.

## Безопасность
Все личные данные сохраняются в `localStorage` текущего браузера. Не используйте этот прототип на общем компьютере для чувствительных записей. Для продакшена нужна отдельная защищенная архитектура.
